# Rolen — Frontend (Next.js)

This is the Next.js frontend for the Rolen School of Fashion and Design website.

See the [project root README](../README.md) for full setup, environment variables, and deployment
instructions — it covers both this app and the `server/` API together.

Quick start (from the project root):
```bash
npm run install:all
npm run seed
npm run dev
```
